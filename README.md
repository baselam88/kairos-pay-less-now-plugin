# Pay Less Now / Pay More Later

Builds the two-door offer: full price later only if satisfied (card on file), or 20-50% off now plus bonuses, sized to break even on acquisition.

A free plugin from KAIROS AI Systems — one focused tool that does one job well for a
small business: no suite to learn, no setup project, no account required beyond your
agent host.

## What it does

Only where a measurable promise resolves in a tight window. If >10% exercise the later-door cancellation, the diagnosis is overpromise, weak criteria, or wrong price — fix that, not the door.

## How to use it

Add this plugin to a compatible agent host (Cursor, Grok Bot, or another
agent-plugins host), then ask in plain language, for example:

> Use the Pay Less Now / Pay More Later to help me: builds the two-door offer: full price later only if satisfied (card on file), or 20-50% off now plus bonuses, sized to break even on acquisition — I'll paste the details.

The plugin works from the facts you give it — your services, your prices, your
records. It never invents a number, a policy, or a result; anything it projects is
labelled an estimate with its basis. Drafts that would go to a customer stay drafts
until you approve them.
